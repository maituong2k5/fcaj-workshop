This section lists and introduces the technical blogs I have posted to [AWS Study Group](https://www.facebook.com/groups/awsstudygroupfcj).

### [Blog 1 - DEPLOY AMAZON S3 FILES WITH TERRAFORM](3.1-Blog1/)

This blog introduces how to deploy Amazon S3 Files using Terraform to automate AWS infrastructure provisioning. It explains how Amazon S3 Files provides an NFS file system interface for accessing S3 data, while Terraform simplifies infrastructure management. The blog also explores networking, IAM permissions, security configurations, and monitoring with Amazon CloudWatch.

### [Blog 2 - UNLOCKING DEEPER INSIGHTS WITH ENHANCED MONITORING IN AWS APPSYNC](3.2-Blog2/)

This blog explores Enhanced Monitoring in AWS AppSync, a feature that provides detailed insights into GraphQL API performance. It explains how Resolver-Level Metrics, Data Source Metrics, and Operation-Level Metrics help developers identify performance bottlenecks, troubleshoot errors, and optimize API operations using Amazon CloudWatch.

### [Blog 3 - AMAZON THREAT INTELLIGENCE OBSERVES THREAT ACTORS RUNNING CYBERCRIME CAMPAIGNS WITH ARTEX AI AGENTS](3.3-Blog3/)

This blog explores how threat actors use ARTEX, an open-source agentic AI framework, to automate cybercrime campaigns. It examines AI-driven credential theft and attempts to bypass identity verification using deepfake technology. The blog also highlights emerging cybersecurity risks and the importance of protecting credentials, securing AI applications, and monitoring suspicious activities.
